# Contributing

Start with the tool and the step you're trying to improve. Each project has its own repository and issue tracker; use the links in the collection README.

For a bug, tell us what you expected, what happened, and which version and browser you used. A small made-up example is ideal. Leave out client files, drive catalogs, cookies, credentials, and `.env` files.

Run the checks listed in that project's README. Meta tests use mocked responses and don't create ads. Atlas tests use temporary folders; don't test cleanup on personal originals.

Update the guide when behavior changes. Keep third-party license notices intact. Please don't add tracking, an activation service, mandatory shout-outs, or promotional text to exported work.

Public credit to @donhkoland is appreciated and optional. License notices still apply to redistributed code.
